# G3 Games Clean UI / Four-Slot Track Design

## 目标

把 G3 Games 浏览态从“软件界面 + 对称轮播”改成“收藏本身就是界面”：浏览时隐藏常驻导航、状态和操作文字，只保留深色动态背景与最多四个实体盒；主盒固定第二槽位，通过严格有方向的轨道动画制造持续收藏队列感。聚焦态保留当前大盒量级，但整体左下调整，与右侧资料/预览区拉开呼吸距离。

## 浏览态

- 同时最多显示 4 个盒。
- 主盒固定第二槽位。
- 四槽故意不对称：左远盒 / 主盒 / 右近盒 / 右边缘盒。
- 主盒在浏览态就承担主要视觉冲击，不再靠聚焦状态暴涨。
- 浏览态不显示游戏标题、平台、游玩时间。
- 非选中盒逐级缩小、压暗、推远；最右盒部分靠近/切入边缘，暗示轨道继续延伸。
- 轮播使用有方向的槽位迁移：向右选择时最左盒继续向左退出，新盒从右边进入；向左反之。禁止同一个可见实例跨屏从左端飞到右端。

## 聚焦态

- 主盒保持大尺寸，但位置从浏览主槽过渡到左下侧聚焦锚点。
- 右侧资料与预览区保留，和主盒之间留明显空隙。
- 后台盒继续存在，但大幅压暗、缩小、推远，只作为环境层，不参与鼠标命中。
- 聚焦状态点击详情区不返回；点击真实空白区域返回浏览态。
- 浏览态隐藏标题；聚焦态文字和预览区按既有淡入动画出现。

## 全局 UI 极简化

- 浏览态/聚焦态隐藏顶部文字 XMB、右上“后端/FPS”、左下操作提示。
- 左下操作说明迁入 System 页面，与功能地图分块显示。
- 右上状态信息仅在 System 页面显示。
- 顶级模块导航改为右下角隐藏式图标抽屉：
  - 内容组：游戏 / 电影 / 漫画 / 音乐
  - 系统组：搜索 / 系统
- 抽屉平时收在右下边缘，只留低干扰提示；鼠标靠近后滑出。
- 图标采用接近 PSP / PS3 气质的线性符号，不显示常驻文字；hover 时图标轻微上浮、放大、提亮。

## System 页面

- 显示连接状态 / FPS。
- 显示操作说明块。
- 显示功能地图/更新状态块。
- 保留添加游戏、窗口/最大化切换、退出 G3。
- 提供“默认启动板块”设置，默认“游戏”。

## 启动状态

- 顶级板块不再按“上次退出所在板块”恢复。
- 启动时读取 `default_start_section`，默认 `games`。
- 允许设置为 games / movies / comics / music / search / system。
- “上次选中的游戏”继续独立记忆和恢复。

## 性能与背景

- Classic Cyan 仍为青色主题，但 Games 背景平均亮度进一步压低为深青黑。
- 大尺度波浪和符号保留，强度更弱；不加入 glow。
- 继续 60 FPS 上限与轻量 3D MSAA。
