# GIGA 批量封面裁剪设计

## 目标

在现有本地影片管理器中增加“GIGA 批量封面裁剪”窗口，处理固定版式：左侧 Back、中间深色 DVD Spine、右侧 Front。批量提取右侧 Front 到集中封面目录，保留原图且默认不覆盖已有正式封面。

## 处理规则

- 支持 JPG/JPEG/PNG/WebP。
- 仅对明显横向双联图自动处理；普通竖向/近方形封面标记为“单张/跳过”。
- 在图像中部区域寻找连续深色竖带，以竖带右边缘作为 Front 起点。
- 从竖带右边缘再向右增加可配置安全边距，默认 3 px。
- 不额外强制裁成 2:3 等固定比例，避免再次损失画面。
- 输出文件沿用原文件名与扩展名；默认已存在时跳过，可显式允许覆盖。
- 检测置信度不足时标记“需复核”，不自动写出。
- 图片损坏时标记“无法读取”。

## UI

主窗口增加“封面工具”按钮，打开批处理窗口。窗口包含源目录、输出目录、3px 安全边距、覆盖开关、扫描预览、批量处理按钮和结果表格。输出目录默认使用当前集中封面目录。

## 数据安全

原始图片只读；输出写到单独目录。默认不覆盖。程序不会修改影片档案或视频文件。处理完成后使 CoverService 索引失效并刷新主界面，以便新封面立即生效。
