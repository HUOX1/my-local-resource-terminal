# 封面处理改良设计

## 目标

在不改动影片数据库、海报墙和永久档案结构的前提下，修正当前封面批处理对“深色/黑色 Spine”的错误假设，并记住用户最近一次的处理参数。

## 已确认行为

- UI 名称由“GIGA 封面批处理”统一改为“封面处理”。
- 原始封面目录记住上一次选择；安全边距记住上一次数值。
- 输出目录仍默认使用软件的集中封面目录。
- 完整 DVD 封面结构仍按“左 Back / 中 Spine / 右 Front”处理，但 Spine 可以是任意颜色、纹理或设计。
- 单张竖版 Front 继续识别为无需裁剪并跳过。
- 原始图片永不修改；正式封面默认不覆盖。

## 裁剪算法

1. 对横向完整封面计算垂直结构边缘强度，不再计算“黑色列”。
2. 在图像中心区域寻找成对的结构边界：Spine 左边界和 Spine 右边界。
3. 利用 Back/Front 宽度大致对称这一结构约束过滤封面画面中的普通竖线。
4. 从集中正式封面目录中的竖版 Front 计算宽高比中位数，作为 Front 比例校验；样本不足时使用 DVD Front 的保守默认比例。
5. 以 Spine 右边界作为 Front 起点，再叠加用户设置的安全边距；右边界永远保持原图最右侧。
6. 如果结构置信度不足或结果比例明显异常，标记“需人工复核”，不自动写文件。

## 设置持久化

`AppSettings` 新增：

- `cover_tool_source_dir: Path | None`
- `cover_tool_margin_px: int`

旧设置文件没有这些字段时：原始目录为空、安全边距默认 0px。关闭封面处理窗口后将当前值写回现有 `settings.json`。
