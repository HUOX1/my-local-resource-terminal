# v0.3.3 第一阶段易用性收尾 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不扩大游戏模块边界的前提下，完成截图媒体浏览器骨架、运行期窗口尺寸保持和封面/GIF安全清除。

**Architecture:** 保持现有 Movie/Game 平行领域结构。截图浏览能力集中在 `GameDetailDialog`，缩略图继续由 `ScreenshotService` 管理；资产所有权和删除集中在 `GameAssetService`/`GameCatalogService`；窗口尺寸只作为 `MainWindow` 运行期 UI 状态，不写 settings。

**Tech Stack:** Python 3.11+, PySide6 Widgets, Pillow, pytest

## Global Constraints

- 不新增依赖。
- 不修改 Movie/Game 数据分域。
- 不实现 Overlay、截图捕获、文件 watcher。
- cache 只存缩略图，不存完整截图原图。
- 源封面/GIF永不因“清除”而删除。
- 主窗口尺寸不跨程序重启持久化。
- 不实现尚未确认的游戏详情/编辑合并。
