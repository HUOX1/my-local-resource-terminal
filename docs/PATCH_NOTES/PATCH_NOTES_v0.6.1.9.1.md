# G3 v0.6.1.9.1 Patch Notes — G1 Visual Tuning / Navigation Handle Repair

## 浏览态四盒重新标定

- 根据 G1 实机帧重新测量四盒中心：约 `20% / 45.5% / 71% / 89%`，替代 v0.6.1.9 过度拉开的 `17% / 44% / 70% / 92%`。
- 近邻盒明显放大：槽位 scale 调整为 `[2.70, 3.35, 2.85, 1.55]`。目标不是把四盒中心挤在一起，而是让盒体本身足够大，边缘接近/轻微压边，形成 G1 的连续队列感。
- 副盒 yaw 收敛为 `[6°, 0°, -5°, -7°]`，不再用大角度侧转制造层级；主要依靠尺寸、Z 深度和亮度区分，减少右侧白色书脊抢眼。
- 保留 v0.6.1.9 的真实屏外出生/回收和串行滚动队列，避免第五盒幽灵回归。

## Preview 聚焦

- 主盒横向锚点从约 `30%` 调到 `26%`，给右侧文字/媒体留出更清楚的呼吸距离。
- 未选中盒不再缩成图标：背景 scale 从约 `0.4–0.5` 提高到约 `1.04–1.28`，视觉面积约为上一版的数倍。
- 背景盒仍使用低亮度和远 Z，不与主盒争夺视觉焦点。

## 右下导航

- 导航柄与抽屉彻底拆成两个独立、直接锚定 viewport 右下角的 Control。
- 抽屉隐藏/动画时不再移动导航柄，因此入口不会跟随抽屉滑出窗口。
- 导航柄改为明确可见的 `≡` 按钮，并加入半透明底、描边；hover 或 click 都可以展开。

## 窗口行为

- 延续 v0.6.1.9 的 G1 式普通可缩放 Windows 窗口；最大化/还原和游戏返回状态保存逻辑不变。
