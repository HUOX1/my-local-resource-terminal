# G3 v0.6.1.9 Patch Notes — G1 Layout / Window / Navigation Repair

## 四盒构图

- 保留 v0.6.1.8 的“四槽、主盒第二槽”，但不再使用固定世界 X 坐标；四槽按当前 G3 窗口宽度约 `17% / 44% / 70% / 92%` 布局，窗口缩放或最大化后会重新计算。
- 槽位尺度调整为 `[1.90, 3.35, 2.05, 1.50]`，让四盒真正占据整个窗口，而不是挤在中央留下大片空白。
- 副盒加入独立亮度层级 `[0.42, 1.00, 0.58, 0.34]`，不再只有大小变化。
- 左/右副盒加入朝相机的收角，尤其压低最右盒因透视暴露出的亮白书脊；封面仍然保持主要可读面。
- Preview 主盒继续沿用 v0.6.1.8 的大尺寸聚焦，只把横向位置改成窗口比例锚点，最大化时不会因为固定世界坐标跑位。

## 滚动幽灵

- 原 `OFFSCREEN_LEFT_X / OFFSCREEN_RIGHT_X` 实际仍落在可视区域内；现改为按当前相机和窗口宽度计算真正的屏外进入/退出位置。
- 连续滚轮不再同时启动多套轨道过渡；滚轮/方向键请求进入队列，一次只执行一个轨道 step。
- 离场实例在下一 step 开始前回收，避免快速滚动时第五、第六个盒同时残留在场景中。

## G1 式窗口行为

- 默认启动恢复为普通、带系统边框、可自由缩放的 Windows 窗口；可使用系统最大化按钮，也可在 System 中切换“窗口 / 最大化”。
- 不再把 borderless maximized 当成默认“全屏”。
- 启动游戏前记录当前窗口模式、边框、尺寸和位置；游戏退出后恢复原状态，不再无条件恢复为最大化无边框窗口。

## 右下导航

- 隐藏抽屉不再只靠窗口边缘 36 px 的不可见热区。
- 右下始终保留一个低干扰的小导航柄；悬停会展开，单击也可展开/收起。
- 导航柄锚定 G3 自己的窗口右下角，因此窗口化、最大化和调整尺寸时都能正常找到。

## 验证

- Python / 静态契约测试：`122 passed`。
- 当前环境没有 Godot Windows 4.7.2 运行时，因此四槽最终观感、窗口系统按钮与实际滚动动画仍需在 Windows 实机验收。
