# G3 v0.6.1.9.2 Navigation Hotfix

针对 Windows / Godot 4.7.2 实机中“右下角导航柄可见，但点击/悬停没有抽屉出现”的修复。

## 改动

- 导航抽屉不再依赖透明度 Tween 才能变得可见；展开时直接 `visible = true`、alpha = 1。
- 导航柄左键增加 `_input()` 级直接兜底，即使普通 GUI `Button.pressed` 路径被其他 Control 干扰，也会执行展开。
- 导航层级提高，避免被自绘窗口栏或其他 UI 层遮住。
- 抽屉和导航柄改用明确的右下角 anchor + offsets，不再依赖相对 position 动画。
- 抽屉与导航柄保持相邻，离开二者后 0.45 秒收起；点击板块后收起。
- 六个入口仍为：游戏 / 电影 / 漫画 / 音乐 / 搜索 / 系统。

## 覆盖方法

完全退出 G3，将 ZIP 内容解压到当前 G3 源码根目录并覆盖同名文件。

本热修不修改用户数据、数据库、游戏资料、轮播参数或 Preview。
