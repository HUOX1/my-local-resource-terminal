# G3 v0.6.1.8 Patch Notes

## 视觉与浏览层重做

- Games 浏览态改为 **最多 4 盒、主盒固定第二槽** 的非对称轨道。
- 浏览主盒本身就是大尺寸，取消“浏览小盒 → 聚焦暴涨”的旧节奏。
- 轨道改为有方向的进入/退出：向右浏览时左端继续向左消失，新盒从右侧屏幕外进入；向左反之，不再让一个盒实例横穿屏幕换边。
- 浏览态隐藏游戏标题 / 平台 / 时间，收藏盒本身成为唯一主视觉。
- 聚焦主盒保持大尺寸但左下移，与右侧资料和预览媒体拉开间距；后台盒继续存在但缩小、压暗、推远并禁止点击。

## 极简 UI

- 顶部文字板块栏默认隐藏。
- 右上“后端 / FPS”和左下操作提示从浏览/聚焦态移除，只在 System 页面展示。
- 顶级板块改为右下角隐藏式图标抽屉；平时只露窄边，鼠标靠近后滑出。
- 内容组：游戏 / 电影 / 漫画 / 音乐；系统组：搜索 / 系统。
- System 页面继续承载添加游戏、窗口切换、退出 G3，并新增“默认启动板块”。

## 启动行为

- 不再按退出前所在顶级板块恢复。
- 新增 `default_start_section`，默认 `games`。
- 上次选中的游戏仍然单独恢复，因此可固定每次进入“游戏”，同时继续停留在上次浏览的收藏。

## G1 视频校正结论

本轮实现参考了 `G1.mp4` 的实际动画，而不是只参考静态截图：浏览态主盒本来就很大；副盒靠尺度、暗度与纵深退场；轮换严格服从单方向轨道；聚焦主要是环境退场和资料进入，而不是主盒再次暴涨。
