# G3 v0.6.1.7 Patch Notes

## 本轮定位

`v0.6.1.6` 的 Windows 实机验收暴露出明显回归：Games 浏览态视觉冲击力不足、聚焦主盒仍偏小、编辑资料文本右键菜单未汉化、透明盒体出现缺面假象、聚焦态后台盒子仍能被鼠标点选，并在放大后发生几何穿插。

`v0.6.1.7` 只处理这些实机问题，不继续扩模块功能。

## 修复

- 浏览态主盒放大到 G1 风格的大主盒量级：主盒 `3.05`，相邻盒 `1.85`，远端盒 `1.05`，横向间距同步扩大。
- 聚焦主盒提升到 `3.30`，并调整锚点避免顶部直接冲出视口。
- 聚焦态后台盒子被推到更深的 Z 层并显著压暗；鼠标命中只允许当前主盒，后台盒子保持视觉存在但不再参与点击/右键/悬停。
- 点击聚焦态真实空白区域重新交给主界面处理，可正常退出 Preview。
- 撤销整个盒体的 Alpha 透明渲染。当前使用“不透明深度写入 + 高 clearcoat + 冷灰蓝材质”模拟磨砂亚克力，避免透明排序/背面剔除造成缺面。
- 编辑资料与启动设置中的 LineEdit / TextEdit 右键菜单增加中文本地化，包括剪切、复制、粘贴、全选、清空、撤销、重做、文字方向、控制字符、表情与符号等。

## 验证

- `PYTHONPATH=. pytest -q`
- 当前结果：`119 passed`
- 仍需 Windows Godot 4.7.2 实机确认最终尺寸、材质观感与鼠标命中边界。
