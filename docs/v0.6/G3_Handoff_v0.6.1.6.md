# G3 v0.6.1.6 交接摘要

## 当前版本定位

- 版本：`0.6.1.6`
- 当前目标：继续打磨 **Games Vertical Slice**
- 产品名：`G3`
- 用户数据目录：`%LOCALAPPDATA%\G3`
- 技术栈：Godot 前端 + Python Core + SQLite + localhost WebSocket

## 本轮已落实的重点

- Games 浏览态改成更接近 G1 直观性的“大封面居中轮播”。
- Preview 主盒明显放大，并把右侧详情区空间让出来。
- 盒体材质进一步走“亚克力半透明”方向，不再是一块板砖式白盒。
- 顶部 XMB 与右键管理菜单继续中文化；System 新增退出 G3 与 `Ctrl+Q`。
- Preview 有了更明确的点击边界与入场动画。
- 项目默认 60 FPS，上轻量 MSAA，背景 shader 简化，继续控制 GPU 压力。

## 仍需优先验收 / 观察

1. 半透明材质在 Windows 实机里的观感是否真的比旧白盒更好。
2. 最小化 / 恢复逻辑是否完全消除了之前的主窗口报错。
3. Preview 动图、视频、音频共存时的观感与提示是否自然。
4. 浏览态轮播是否已经足够接近想要的“G1 成熟感”。

## 当前最明确的后续待办

- 媒体素材管理 UI
- 移除收藏确认流程
- 如有必要，为 Games 增加多种浏览布局模式
- 继续根据实机结果打磨材质、灯光、性能与交互细节
