# G3 v0.6.1.7 交接摘要

## 当前版本

- 版本：`0.6.1.7`
- 当前主线：Games Vertical Slice
- 前端：Godot 4.7.2
- 后端：Python Core + SQLite + localhost WebSocket
- 数据：`%LOCALAPPDATA%\G3`

## G1 / G3 命名

- `G1`：旧原型机 / v0.5 系列设计参考。旧代码与旧日志不回溯改名。
- `G3`：当前 Godot + Python 架构主线。

## 当前 Games 展示语言

- 浏览态：以 G1 为主要视觉参考，中央大主盒 + 左右邻近盒，强调收藏品本体而不是小型列表。
- 聚焦态：主盒向左放大，右侧显示资料与 Preview；后台盒子仍存在，但只作为压暗背景，不参与鼠标点击。
- 盒体：真实 GLB，正式模型 `g3_frontend/assets/models/cases/standard_tall.glb`；中文节点 `盒体` / `封面正面`。
- 材质：暂不使用整个盒体 Alpha 半透明。现阶段用不透明深度写入 + clearcoat 模拟磨砂亚克力，等未来有独立透明外套网格再做真正透明层。

## v0.6.1.7 重点修复

1. 浏览态主盒显著放大，重新追求 G1 的视觉冲击力。
2. 聚焦主盒继续放大。
3. 文本编辑右键菜单补中文。
4. 修复透明材质导致的缺面假象。
5. Preview 状态后台盒子不再接受鼠标点击/右键/悬停；空白点击可返回。
6. 后台盒子在 Z 轴拉开并压暗，避免与聚焦主盒穿模。

## 优先实机验收

- 1600×900 下浏览主盒是否达到想要的 G1 冲击力。
- 聚焦主盒是否足够大且不裁切。
- 旋转主盒时顶部、边缘、开口是否完整，无“透明缺面”。
- 点击后台盒子和主盒旁空白是否不会误切游戏。
- 编辑资料 / 启动设置文本右键菜单是否全部中文。
