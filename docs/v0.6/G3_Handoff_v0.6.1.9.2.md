# G3 v0.6.1.9.2 交接摘要

## 本轮目标

继续按 G1 实机观感修补 Games Vertical Slice，不扩新模块。

## 已调整

- Browse 四槽仍为 `20% / 45.5% / 71% / 89%`，最右槽 scale 改为 `2.15`。
- 离场盒只向屏外滑出，不再强制缩到 `0.62`。
- 导航 handle 的 click 与 hover 都只展开，修复“鼠标先经过、点击反而立即关闭”。
- Windows 原生标题栏撤掉；新增 G3 自绘主题标题栏，保留拖动、缩放、最小化、最大化/还原、关闭。
- 右上操作/错误提示 4 秒后淡出。

## 保留参数

- Preview selected X：`0.26`
- Preview selected scale：`3.42`
- Preview background scale：`1.04–1.28`
- 串行滚动队列与动态真正屏外坐标继续保留。

## Windows 实机重点

1. 右近盒移动到最右槽时是否不再突然急缩。
2. 最右盒离场时是否只平滑滑走，不再像被吸到角落。
3. 右下 `≡` 点击是否稳定展开六个入口。
4. 自绘标题栏拖动 / 最大化 / 还原 / 最小化 / 关闭是否正常，窗口四边和四角是否可缩放。
5. 右上提示是否约 4 秒后自然淡出。
