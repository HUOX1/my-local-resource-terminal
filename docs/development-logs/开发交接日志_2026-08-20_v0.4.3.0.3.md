# 已完成工作

## 一、Poster Wall Engine 海报墙引擎

### 原问题

旧版海报墙依赖 Qt 默认布局行为：

-   QListView
-   IconMode
-   Wrapping
-   ResizeMode.Adjust

导致：

-   窗口缩放时海报位置异常；
-   海报延迟补位；
-   列数变化时出现跳动；
-   Qt 自身布局逻辑与自定义视觉目标冲突。

------------------------------------------------------------------------

## 修改结果

改为自定义海报布局控制。

当前规则：

-   固定左侧起点；
-   自定义列数计算；
-   弹性列间距；
-   保持海报自然比例；
-   不强制裁切；
-   不产生右侧巨大空白。

------------------------------------------------------------------------

## 最终确定布局策略

采用：

**固定左锚点 + 弹性间距**

效果：

-   第一张海报位置稳定；
-   窗口变化时不会整墙漂移；
-   宽窗口时剩余空间分散到列间；
-   窄窗口时正常换列。

原因：

优先保证窗口调整过程中的稳定感。

# 未采用方案

## 二、Rail Handle 独立悬浮控件方案

### 目标

将主轴梯形把手从 Qt splitter handle 中拆出，成为独立 UI 控件。

目标结构：

    MainShell

    ├── Rail
    ├── Content
    └── RailHandleWidget

------------------------------------------------------------------------

## 实验结果

该方案未通过。

问题：

-   自定义 Handle 与 QSplitter 管理机制冲突；
-   主轴布局异常；
-   内容区域尺寸受到影响；
-   后续修复过程中导致梯形把手不可见。

------------------------------------------------------------------------

## 决定

放弃 v0.4.3.0.4 路线。

不要继续从该版本开发。

恢复原则：

-   以 v0.4.3.0.3 为基础；
-   保留 QSplitter 的布局所有权；
-   只修改 handle 的绘制和交互表现；
-   不把额外 QWidget 插入 splitter 管理结构。

------------------------------------------------------------------------
