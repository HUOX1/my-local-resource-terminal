Retro v0.5.0.17.1 - Windows idle performance smoke budget fix

Prerequisite: v0.5.0.17.1 Performance Hotfix already applied.

Changes:
- Fixes false FAIL in `idle ambient repaint budget` on native Windows.
- Waits for native show/hover settling before timing.
- Measures app-owned ambient QTimer timeout rate instead of treating every OS Paint event as an animation frame.
- Prints both ambient timeout count and raw paint-event count for diagnostics.
- Renames the check to `idle ambient timer budget`.

No production rendering/audio/UI code is changed by this patch.
