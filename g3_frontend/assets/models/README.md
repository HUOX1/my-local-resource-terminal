# G3 游戏盒 3D 模型规范

当前第一种正式盒型：`g3_frontend/assets/models/cases/standard_tall.glb`。

G3 优先加载这个标准高盒；如果正式资源缺失，仍保留旧 `game_case.glb` 与 `game_case_placeholder.glb` 作为兼容 / 故障回退。

## Blender / GLB 接口

- 格式：glTF 2.0 Binary (`.glb`)
- 导入 G3 后：`+Y` 向上、`+X` 向右、正面朝 `+Z`
- 原点：盒子几何中心附近
- 当前标准高盒按真实尺寸建模：约高 `190 mm`、宽 `135 mm`、厚 `15–18 mm`
- G3 当前 3D 场景沿用早期展示尺度，因此运行时对真实尺寸标准盒应用 `10x` 显示缩放；不要为了适配场景破坏 Blender 母版的真实尺寸。
- 建议三角面：`500–2000`
- 不烘焙灯光 / 阴影

## 必需节点 / 网格命名

面向建模者的正式中文接口：

- `盒体`：主体塑料盒
- `封面正面`：正面封面区域，必须独立网格，UV 使用完整 `0–1`
- `封面书脊`：可选
- `封面背面`：可选

运行时仍兼容旧英文接口 `case_plastic` / `cover_front` / `case_spine`，但新模型默认使用中文命名。

`封面正面` 不应烘焙具体游戏封面。G3 在运行时根据当前游戏的 `cover` 素材路径创建纹理并替换该网格材质。
