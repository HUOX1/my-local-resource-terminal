# G3 游戏盒 3D 模型规范

正式模型文件名：`game_case.glb`

G3 会优先加载 `game_case.glb`；若不存在，则加载仓库自带的 `game_case_placeholder.glb`。占位模型只用于验证真实 3D 资产管线，不是最终美术资产。

## Blender 建模建议

- 格式：glTF 2.0 Binary (`.glb`)
- 正面朝向：`+Z`
- 上方：`+Y`
- 右方：`+X`
- 原点：盒子几何中心
- 导出前 Apply Rotation / Scale，最终旋转 `0,0,0`、缩放 `1,1,1`
- 建议显示尺寸：高 `1.90`、宽 `1.35`、厚 `0.15–0.18` Blender Unit（只要求比例一致）
- 建议三角面：`500–2000`
- 不烘焙灯光/阴影
- 保留一套正常 UV

## 必需节点 / 网格命名

为了让 G3 自动替换材质，至少保留：

- `case_plastic`：盒体塑料
- `cover_front`：正面封面区域
- `case_spine`：书脊（可选，但推荐）

`cover_front` 最好是独立 Mesh，UV 覆盖完整封面 0–1 区域。这样 G3 能直接把用户封面图贴上去。

如果你想做透明塑料膜、卡扣、圆角、边缘倒角，都可以做，但不要把封面图直接烘焙进模型。
