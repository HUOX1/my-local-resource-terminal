# 本地资源终端 Phase 2.1 Flat Baseline 设计

## 目标

在 v0.3.4.7 第一阶段冻结基线上，只重做主界面的视觉壳与全局 Qt 视觉语言，让程序获得一套现代、克制、可继续换肤的扁平基线；影片、游戏、计时、备份恢复、扫描、详情与数据语义保持不变。

## 核心结构

- 保留标准 Windows 顶层窗口与系统 resize/titlebar，不再做无边框玻璃实验。
- 主界面改为固定左侧导航 + 右侧内容区。
- 左侧只放影片、游戏、设置三个真实入口；不添加尚不存在的媒体领域。
- 右侧顶部为库级工具栏：搜索、筛选、排序、升降序、视图切换、扫描/封面工具/添加游戏。
- 内容区继续复用现有 Movie/Game models、delegates、右键菜单、双击行为和缓存。
- 底部继续使用 QStatusBar 承载扫描状态、库数量和游戏计时。

## 视觉系统

新增集中 `FlatTokens` 与应用级 QSS：深灰背景、分层 surface、低对比边框、近白主文字、灰色次文字、蓝色强调色、小圆角、统一控件高度与 spacing。业务文件不散落十六进制颜色。

影片/游戏封面仍保持自然宽高比、无常驻标题文字；仅增加圆角裁切、hover/selected 细边框，缓存策略不变。

## 兼容边界

- 不修改 JSON、SQLite、Session、扫描、播放器、启动器、备份恢复逻辑。
- 不新增第三方依赖。
- 不做无边框、玻璃、透明、动画或完整皮肤引擎。
- 保留 v0.3.4.7 作为回归基线。
