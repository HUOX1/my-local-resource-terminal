# 本地资源终端 v0.4.1.9 设计规格：一级分类文件夹 + 影片独立档案页

## 目标

在不重新设计第一阶段成熟业务的前提下，为 Movie/Game 两个媒体库加入一级虚拟分类文件夹，并将影片档案从独立 QDialog 升级为占据主内容区的独立页面。

## 边界

- 分类文件夹只有一级，不允许嵌套。
- 文件夹是终端内部组织关系，不移动影片文件、游戏目录、EXE、模拟器、截图或封面源文件。
- 一个影片/游戏至多属于一个分类文件夹；跨分类继续使用既有标签。
- 文件夹定义是永久数据，跟随 Data 目录、数据迁移和备份恢复。
- Movie/Game 保持平行领域模型，不创建万能 Resource 表。
- 影片档案本轮只展示现有字段，不新增联网刮削、演员头像、剧照抓取、简介抓取或电视剧 Season/Episode。
- 电视剧未来作为 Movie 领域新的作品类型/内部 Season→Episode 结构设计，不由分类文件夹承担层级。

## 分类文件夹数据设计

永久定义文件：`Data/collections/folders.json`。

每个文件夹包含：
- `id`: UUID
- `domain`: `movies` 或 `games`
- `name`: 当前领域内大小写不敏感唯一
- `created_at`: ISO 时间

影片和游戏永久 JSON 各增加可选 `folder_id`。SQLite 的 `movies`、`games` 也增加可空 `folder_id` 作为查询索引字段；SQLite schema version 升至 5。

文件夹删除时先清空该领域中所有引用它的档案 `folder_id`，再删除文件夹定义；不会删除任何档案或媒体文件。

## 分类文件夹 UI

保持 v0.4.1.7 之后的极简主界面，不恢复顶部常驻工具栏。

底部放大镜弹出面板增加“分类文件夹”区：
- 文件夹下拉框：`全部内容` + 当前领域一级文件夹。
- “新建分类文件夹”按钮使用“放大镜镜框内 + 号”的 `search_add` 图标。
- 选中具体文件夹时可低调重命名/删除。

海报墙仍只展示海报，不混入文件夹卡片。进入文件夹本质上是当前库的组织过滤；底部状态改为 `文件夹名 · N 部影片` / `文件夹名 · N 个游戏`。

影片/游戏右键菜单加入“移动到文件夹”子菜单：
- 未分类
- 现有文件夹列表

影片多选批量菜单也支持移动到文件夹。游戏当前仍为单选，不扩大多选功能。

## 影片独立档案页

新增 `MovieArchivePage`，加入 `MainWindow.content_page_stack`，行为与游戏独立档案页一致：
- 左上角 `←` 返回影片海报墙。
- 占据整个右侧内容区；左侧 Identity/Main Rail 保留。
- 不新增网络数据源。
- 展示当前已有信息：封面、编号、标题、演员、系列、厂商、发行日期、标签、评分、收藏/已观看、备注、字幕、本地可用状态、观看次数/首次/最后观看、分辨率、时长、视频/音频编码、文件大小、本地路径。
- `播放影片` 是主要动作。
- `编辑档案` 打开现有 `MovieDetailDialog`，继续复用成熟的编辑、换封面、关联本地文件、删除档案能力。
- 档案被编辑/播放后，独立页面刷新当前记录。
- 右键“影片档案”改为打开独立内容页，不再直接弹旧详情对话框。
- 影片海报双击仍保持第一阶段行为：直接播放。本轮不更改。

## 数据安全 / 备份

- `DataDirectoryMigrator` 同步迁移 `Data/collections/`。
- Backup format 升到 v4，新增 `data/collections/folders.json`。
- 恢复 v4 时恢复文件夹定义；恢复 v1/v2/v3 时按“该备份时代没有分类文件夹”处理，清空当前文件夹定义，避免新状态污染旧备份。
- 恢复回滚快照必须包含 `collections/`。
- 旧 Movie/Game JSON 缺少 `folder_id` 时安全回退为未分类。
